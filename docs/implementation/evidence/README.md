# Evidencia de tareas

Cada tarea crea una carpeta propia:

~~~text
docs/implementation/evidence/FNC-XXX-000/
├── README.md
├── commands.txt
├── test-results/
└── decisions/
~~~

No almacenar secretos, datos reales, dumps, binarios grandes ni logs con payload sensible. Para resultados grandes se registra hash, ubicación autorizada y retención.

La evidencia mínima identifica commit, ambiente, versiones, comando, fecha y resultado.
