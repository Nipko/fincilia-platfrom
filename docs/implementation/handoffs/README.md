# Handoffs

Cada agente entrega un archivo único FNC-XXX-000.md basado en ../templates/HANDOFF.md.

El handoff:

- No sustituye tests ni revisión.
- No modifica estado global; Integration Steward lo hace.
- Debe permitir reproducir la validación sin leer conversaciones.
- Registra trabajo pendiente con IDs, nunca TODO anónimos.
