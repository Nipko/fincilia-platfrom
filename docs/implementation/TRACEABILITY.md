## Campos al implementar

- Requirement ID y versión.
- Tarea.
- ADR/decisión.
- Ruta o símbolo implementado.
- PR y commit.
- Test IDs y comando.
- Evidencia.
- Gate.
- Owner.
- Estado.

Un cambio material crea nueva versión del requisito o decisión; no reutiliza silenciosamente el ID.
