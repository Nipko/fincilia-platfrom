# ADR-010 — Responsabilidades web y móvil

- Status: Accepted
- Date: 2026-08-21
- Owners: Product + UX + Mobile + Security, accountable FOUNDER-01
- Gate: S1-READY
- Plan refs: §12, §20

## Decision

Web:

- Mapping complejo, conciliación masiva, reglas, conectores, report builder y cierre final.

Móvil:

- Cámara/upload, solicitudes, recordatorios, alertas genéricas, comentarios y decisiones simples con evidencia mínima.

Móvil inicial no cierra/reabre periodos ni ejecuta acciones complejas. Push no revela montos sensibles.

## Consequences

App sencilla y segura; algunas tareas requieren volver a web.

## Verification

Prototipo demuestra límites, step-up y estados degradados antes del scaffold móvil.
